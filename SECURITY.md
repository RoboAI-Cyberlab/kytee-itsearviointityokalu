# Security Policy

## Supported Versions

Only the latest version is supported with security updates.

## Reporting a Vulnerability

Please report vulnerabilities by email to **teemu.jonkkari@samk.fi**.

You can expect an acknowledgement within 5 business days. If the vulnerability is accepted, a fix will be prioritized based on severity. If declined, you will receive an explanation. Please do not disclose the vulnerability publicly until it has been addressed.

## Data Handling

The application runs entirely in the browser. Assessment answers and organization details are stored only in the browser's local storage and are not sent to any server.
